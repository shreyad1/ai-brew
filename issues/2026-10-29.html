Word of the Day
Tool calling
Agents, 1 of 5

"The model should call the search tool instead of answering from memory."

A model's ability to request that your code run a named function with structured arguments, then use the result in its answer. Also called function calling.

Like a barista who can ring the kitchen for a pastry instead of pretending to bake it.

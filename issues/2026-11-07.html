Word of the Day
Knowledge graph
Retrieval and knowledge, 5 of 5

"Ground the agent on the knowledge graph so it knows which team owns which system."

Data stored as entities and the relationships between them (e.g. Customer → bought → Product), which can be queried by following those links.

Like a map of which farm supplies which roaster, which supplies which café.

Word of the Day
Agent loop
Agents, 3 of 5

"Cap the agent loop at 10 steps so it can't run forever."

The cycle an agent repeats until it is done. The model decides on an action, code runs it, and the result goes back to the model to decide the next step.

Like taste, adjust, taste again until the drink is right.
